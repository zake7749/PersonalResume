# PersonalResume

The 2015 site that used to live here has moved to
**<https://zake7749.github.io/AboutMe/>**.

This branch is what GitHub Pages serves. Every page redirects: each one is an
HTML page with a canonical link, a meta refresh and a script that replaces the
top window. GitHub Pages cannot serve a real 301 for a project site, and the
old site was a frameset whose navigation used `target="main"`, so an old link
can still open a page inside a frame.

The original pages remain in the history, up to `438846b`.
